**Decision: adapt. Access blockers: none.** Best starting point for a small Edge page-service adapter plus Python reconciliation, with substantial changes before autonomous use.

Exclude SBC solver, catalog database, dashboard and MCP if unnecessary for the minimal harness.

However [FC27RequestHandler.do_POST](https://github.com/liusihang/fc27-copilot/blob/fa0fdde132715b2c09a4cff1e51736a1794d635e/fc27/daemon.py#L673) exposes browser-response/RPC/MCP routes without an explicit authentication or Origin check in this handler; [serve](https://github.com/liusihang/fc27-copilot/blob/fa0fdde132715b2c09a4cff1e51736a1794d635e/fc27/daemon.py#L756) defaults to loopback but permits an environment host override.
